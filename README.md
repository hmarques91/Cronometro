# 🕒 Cronômetro com JavaScript, HTML e CSS

Este projeto é um **cronômetro funcional** desenvolvido com **HTML, CSS e JavaScript puro**, criado com o objetivo de praticar manipulação do DOM, controle de intervalos (`setInterval` / `clearInterval`) e lógica de tempo em segundos, minutos e horas.

---

## 🚀 Funcionalidades

- ⏯️ **Iniciar** — inicia o cronômetro do zero ou retoma após pausa.  
- ⏸️ **Pausar / Retornar** — pausa a contagem e alterna o texto do botão dinamicamente.  
- 🔄 **Zerar** — interrompe o cronômetro e redefine o tempo para `00:00:00`.  
- 🎨 **Estilização com CSS** — botões com feedback visual (ex: botão “Retornar” muda para vermelho).  
- 🔒 **Controle de estado** — impede iniciar múltiplas contagens simultâneas.

---

## 🧠 Conceitos praticados

- Manipulação do DOM com `querySelector`  
- Uso de **event listeners** para capturar cliques  
- Controle de intervalos com `setInterval()` e `clearInterval()`  
- Condicionais para alternar comportamento dos botões  
- Formatação de tempo usando `String().padStart()`  
- Classes dinâmicas com `classList.add()` e `classList.remove()`

---

## 🧩 Tecnologias utilizadas

- **HTML5**  
- **CSS3**  
- **JavaScript (ES6)**  

---

## 📸 Exemplo de funcionamento

```bash
00:00:00  →  Iniciar  →  Cronômetro começa a contar
⏸️ Pausar  →  Contagem interrompida, botão fica vermelho
▶️ Retornar →  Contagem continua
🔄 Zerar   →  Tempo volta para 00:00:00
